# Gráficos do Ninja Forest Run

Esta pasta foi criada para receber os gráficos do jogo. Para evitar problemas de licença e manter o projeto reutilizável, os visuais do jogo serão produzidos/organizados para uso próprio, sem copiar sprites de terceiros.

Referência visual pesquisada: packs de pixel art de floresta/ninja com licença apropriada. O jogo atual usa Canvas e pode ser adaptado para carregar PNGs/SVGs desta pasta.
